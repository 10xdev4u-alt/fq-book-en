# BarbaTunnel

!>BarbaTunnel has not been updated for many years, and the VPN server may have had some problems of its own, making the software less useful; I tested it and it was not very satisfactory to say that the connection to OpenVPN was unsuccessful.

BarbaTunnel is a non-independent tunnel that should run a tunnel application or use a standard VPN connection after the BarbaTunnel operation. If the firewall prevents the VPN connection or prevents the speed of the VPN connection from decreasing, it may help.
