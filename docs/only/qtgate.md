# CoNET

!>The project had problems with the poor validation of mailboxes and the misuse of incoming and outgoing mail to the extent that it was not possible to use the related wallbreaking services effectively and was not recommended for use

> Original language:[QTGate/CoNET](https://github.com/QTGate/CoNET)&emsp; by:[CoNET](https://github.com/QTGate)

CENET is a tool to counter cyber surveillance. Users have access to CoNET's anonymous virtual network by connecting to third-party public mail servers.[Refraction Network](https://zh.wikipedia.org/zh-cn/%E6%8A%98%E5%B0%84%E7%BD%91%E7%BB%9C), which allows users to avoid being monitored by the network and to access servers that are blocked by the network.
