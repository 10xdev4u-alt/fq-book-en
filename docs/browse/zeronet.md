### Document verify MD5, SHA1 values

Each file can obtain a authentication code using an algorithm, and the MD5 and SHA1 values of the document are a string of characters obtained from the calculation of the file data using the corresponding special algorithm. Because this algorithm is almost impossible to reverse, we can assume that a document corresponds to a specific MD5, SHA1.

So, when we download the file, we can calculate the MD5, SHA1 values after the download is completed, compared to MD5, SHA1 values provided by the document provider, and if the calculation does not match the description given by the provider, then the document you download is incomplete or has been manipulated.-->
