> *Network Bandwidth/flow: 2TB/month – Soft
> *Shared DB processing/System: Max 200msec per second CPU time – Soft
> *Dyno RAM usage/Use running memory: 512MB – Hard
> :: Slug Size/storage space: 300MB – Hard
> * Request Length/ Request Time: 30 seconds – Hard
