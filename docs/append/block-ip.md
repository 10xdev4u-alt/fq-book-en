# The idea of a blockade on IP

With an IP address shield, all backbone routers and internationally exported routers have been added to the IP blacklist related to Google services, and data packages with the relevant IP address have been dropped on the halfway line, which would place a significant burden on routers and be very costly.

Most of this strategy is directed at social communication websites and politically motivated organizational parties or organizations, which, of course, also have server IP addresses for individuals or providers with frequent Internet connections; for websites that are perceived to be unharmonized and not very widespread, the blockade strategy does not use this means, but rather uses a cheap, much more effective DNS contamination.

* A new IP address for the site, the user basically doesn't feel any change, but the change of domain name loses a large number of users.

* Routers are only responsible for falsifying search results, which is much lower than the use of IP address shielding resources based on routers.

In particular, many mainstream Internet portals abroad will never lose a large number of other users by changing domain names because domestic users do not see their own websites, thus making the GFT DNS contamination permanent.
