# Software interconnection protocol mechanisms

Software using network protocol orientation:

* Unstated queries initiated intermittently by clients and delays allowed, using http/https, e.g. browser
* If both the client and the server are available independently:
    * Tolerable delays, but not a byte for data, using tcp, e.g., online landowners
    * There is a real-time requirement to allow some byte errors, but delays cannot be tolerated, using dup, e.g., an instant action type game
