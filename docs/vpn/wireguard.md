# wireguard

Enter[wireguard](https://www.wireguard.com/install/)Download

![](https://i.postimg.cc/d0Ny2kxH/Snipaste-2019-10-04-10-49-28.png)

Open wireguard Selection`add empty tunnel`and copy`public key`Public Key Value

![](https://i.postimg.cc/FR2w1Vkf/00-05.png)

Enter[cryptostorm.is/wireguard](https://cryptostorm.is/wireguard), copy the public key to`your wireguard public key`option,`add key`Continue and generate profile

![](https://i.postimg.cc/MHB0Ky1p/27-48.png)

Copy Profile to`public key`Below Configure Info box and delete unnecessary fields

```
[Interface]
PrivateKey = YOUR_PRIVATE_KEY
```

![](https://i.postimg.cc/BbRhmSBX/41-15.png)

Click`active`Activate

![](https://i.postimg.cc/65gwLTRh/50-10.png)

Test

![](https://i.postimg.cc/zvz1SjPK/56-26.png)
