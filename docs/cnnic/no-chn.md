## ping

Some readers may find it odd that the next map points and IPs are all ping-up, but this is a phenomenon where web pages cannot be accessed.

![](https://i.postimg.cc/50gC6Nkz/54.png)

Ping is not part of the application level http protocol, but rather the web level ICMP protocol, so sites and IPs are all ping-through, but simply cannot access the web page. This has to do with the TCP reset attack.[Please see the outline for the digital certificate.](abc/dc_zhenshu.md)
